# Confirmed challenge requirements

- Mobile phone catalog with a product listing.
- API-based real-time search by product name or brand.
- Product details with color and storage selection.
- Dynamic product image and price based on selection.
- Similar products.
- Persistent cart with total and item removal.
- Responsive design and accessibility.
- Tests, linters, and formatters.
- A clean browser console: no warnings or errors.
- A detailed final README.
- External REST API requests require the x-api-key header. The real key must not appear in this document.

This is the confirmed scope, not a complete API contract or visual specification. Endpoint schemas, precise interaction details, and supplied designs must be verified from challenge materials before implementation; do not invent requirements.
